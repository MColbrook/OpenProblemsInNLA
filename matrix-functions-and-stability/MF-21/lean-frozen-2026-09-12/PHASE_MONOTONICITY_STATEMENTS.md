# Phase monotonicity: statement lock

For the actual manuscriptEta, m≥1, derive a positive uniform bound for
both its value and first derivative on `[0,π]` from local smoothness and
compactness. No bound is a new hypothesis.

Define `F_n(θ)=(n+2)*θ-manuscriptEta m θ`. Prove its exact derivative
`n+2-deriv(manuscriptEta m) θ`, endpoint values
`F_n(0)=-(m-1)*π/2`, `F_n(π)=(n+1)*π`, and that there is N such that for
all n≥N and all θ∈[0,π],

```
(n+2)/2 ≤ F_n'(θ) ≤ 2*(n+2).
```

Deduce strict monotonicity on `[0,π]` for these n. This is equation (20),
with exactly the n+2 normalization. It does not give bounds for E_n or
identify the eigenangle indices; those parts of Lemma 4 remain separate.
