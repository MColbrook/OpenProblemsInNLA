# Smooth quadratic branch: statement first

Continue the exact quadratic branch of Lemma 2 by defining

`r_kappa(theta) = stableQuadraticRoot (kappa * sin(theta/2))`.

For complex `kappa` with positive real part, this function on the real
line is infinitely continuously differentiable. At theta=0 its value is
1 and its derivative is `-kappa`, the coefficient in manuscript (8).
For `0<theta≤pi`, it has norm strictly less than 1; it never vanishes.
For all theta it satisfies the exact reciprocal equation with right side
`-4*kappa^2*sin(theta/2)^2`.

Smoothness is to be derived from the actual square-root function on the
slit plane; no smooth-root assumption is allowed. The stronger global
extension simply supplies the neighborhood extension used in the proof.
The roots-of-unity specialization, distinctness, phase and exponential
estimates are not part of this module.
